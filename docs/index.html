3EVO Router

Local-first AI gateway + web dashboard ("Endpoint Proxy"). One OpenAI/Anthropic-compatible endpoint, multi-account rotation, 3-tier fallback combos, RTK token compression.

GitHub Docs Live Panel Demo

Single endpoint

OpenAI, Anthropic, Responses, /models.

Format translator

OpenAI ↔ Anthropic ↔ Gemini.

3-tier fallback

primary → low-cost → free/credit.

RTK compression

Measured token savings on tool_result.

Multi-account

Round-robin / priority rotation.

Security

AES-256-GCM vault, SECRET_PATH, CORS.

Architecture

Client (OpenAI/Anthropic SDK)
  │
  ▼
┌─────────────┐
│  Gateway    │  /v1/*  (Next.js API routes)
│  Translator │  (canonical format)
└──────┬──────┘
       │
   ┌───┴───┐
   │ Router │  combos, tiers, rotation, circuit breaker
   └───┬───┘
       │
   ┌───┴─────────────────────┐
   │ Providers / Accounts     │  OAuth, API-key, compatible
   └───┬─────────────────────┘
       │
   ┌───┴───┐
   │  RTK  │  tool_result compression
   └───┬───┘
       │
   ┌───┴───┐
   │ Vault │  AES-256-GCM secrets (SQLite ~/.3evo)
   └───────┘
